WinFrame Windows Automation Framework

Local & Remote Keyword-Driven + Object-Oriented Windows Test Framework uniting Win32 Native P/Invoke, Microsoft UI Automation (UIA), OpenCvSharp4 Vision & Snipping, Win32 GDI Control Outlining, Developer Step & Inverse Range Execution, and Process Re-Harnessing.

GitHub Repository • GNU GPL v3.0 License

Architecture & Deliverables

1. WinFrame.Core.dll (Embeddable Class Library)

Attach directly to any Windows Forms, WPF, or console project. Provides Win32Automation, UiaAutomation, OpenCvAutomation, Win32Highlighter, ProcessManagementEngine, ControlRepository, StepQueueController, and OOP base classes (TestBase, ScreenObject, UIControl).

2. WinFrame.App.exe (Desktop Studio)

Includes the Hand of Glory splash screen, notification tray icon with scrolling marquee status, Load Tests Queue pipeline, Developer Step Forward / Inverse / Range (1-3, 4-1) bar, and Create Tests recorder with the right-hand Accessory Control Naming Panel.

3. WinFrame.Cli.exe & WinFrame.Service.exe

Run test queues, step ranges, inverse rollbacks, control scraping, or host the REST API service (/api/queue/run, /api/step-queue/next, /api/step-queue/prev, /api/step-queue/range) on local or remote machines.

Developer Step Queue, Rule-Based Inversion & Range Execution

Run steps one by one, step backward with automatic rule-based inversion (entering text becomes deleting text; checking becomes unchecking; expanding becomes collapsing), or execute any forward or reverse range:

// C# OOP & StepQueueController example
var engine = new KeywordFramework();
var controller = engine.CreateStepController(myTest, autoInverseOnError: true);

controller.StepNext();                   // Step 1 forward
controller.StepPrevious(useInverse:true);// Reverses step 1 using StepInversionEngine
controller.ExecuteRange("1-3");          // Runs steps 1, 2, 3 forward
controller.ExecuteRange("4-2");          // Walks 4 -> 3 -> 2 in reverse and executes each step's inverse!

Win32 GDI Control Highlighting

Set highlight = "1" or "true" in config/test variables to outline every targeted control with a Win32 GDI pen for the configured short interval (set to "0", "", or null to turn off), or use the special HIGHLIGHT keyword command in any sheet:

ActionTargetValueDescription
HIGHLIGHT@button_1,@edit_1#F59E0B|280|3Outlines controls with Win32 GDI when highlight=1/true
UIA_INVOKE@button_1Invokes UIA InvokePattern (with native click fallback)
UIA_SET_VALUE@edit_1Hello WorldSets value (inverse automatically clears/restores text)
